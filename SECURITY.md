# Security policy

## Supported versions

Only the latest release receives security fixes.

## Reporting a vulnerability

Please do **not** report security problems in a public issue.

Report them privately through GitHub instead: open the
[Security tab](https://github.com/simply-justin/ha-piratenfm/security) of this repository and click
**Report a vulnerability**. Include:

- what an attacker could do, and under which conditions;
- steps to reproduce, or a proof of concept;
- the versions of the integration, Home Assistant and Music Assistant you used.

You can expect a first response within a week. Once a fix is released, you are credited in the
release notes unless you prefer otherwise.

## Scope

In scope:

- The code in this repository, including how it handles responses from Piraten.FM and how it
  stores and uses the Music Assistant access token.

Out of scope:

- Piraten.FM itself, Music Assistant and Home Assistant. Please report those to their own
  maintainers.
