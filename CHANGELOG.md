# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project
adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Security policy, issue templates and a pull request template.

### Changed

- Reworked the README: quick start with one-click HACS and setup buttons, highlights and a clearer
  structure.

## [0.2.0] - 2026-11-23

### Added

- Managed radios get the Piraten.FM logo as cover. Radios added by 0.1.0 receive it on the first
  sync after updating.

## [0.1.0] - 2026-11-23

### Added

- Initial release: syncs the stations that are on air on Piraten.FM into the Music Assistant
  library, with safe removal of offline stations, crash-safe state, sensors, a sync button,
  switches, diagnostics and a service to remove all managed radios.
